# Как выложить Gyvenimas Vilniuje на Lovable (рейтинг + облачное сохранение)

Схема та же, что у Finance Midterm Trainer: статичный HTML на Lovable и Supabase как база.
Все таблицы и функции этой игры начинаются с `ltv_`, поэтому можно взять тот же проект Supabase,
что и для finance please. Таблицы двух игр не пересекаются.

1. В Lovable создай проект (или открой существующий) и подключи **Supabase**.
2. В Supabase открой **SQL Editor**, вставь весь `supabase.sql` из этой папки и нажми **Run**.
   Скрипт создаёт таблицу `ltv_leaderboard`, закрытую таблицу `ltv_cloud_saves` и функции
   `ltv_cloud_login`, `ltv_cloud_save`, `ltv_cloud_load`, `ltv_lb_submit`. Запускать повторно безопасно.
3. В Supabase: **Project Settings → API**. Скопируй `Project URL` и `anon public` key.
4. Положи `index.html` из этой папки в проект Lovable, например как `public/vilnius.html`
   (или `public/game.html`, если это отдельный проект).
5. В этом файле перед первым `<script>` добавь строку:

   ```html
   <script>window.LB_CONFIG={supabaseUrl:'https://ТВОЙ-ПРОЕКТ.supabase.co',supabaseKey:'ТВОЙ_ANON_KEY'};</script>
   ```

6. Опубликуй проект.

Что получит игрок во вкладке **Рейтинг**:

- **Аккаунт**: ник + PIN из 4–12 цифр. Если ник свободен, аккаунт создаётся, если занят, нужен его PIN.
  После 5 неверных PIN подряд вход по этому нику блокируется на 15 минут.
- **Облачное сохранение**: весь прогресс (текущая жизнь в игре, статистика ошибок по всем комбинациям,
  список ошибок, рекорды, настройки) сохраняется сам каждые 20 секунд при изменениях и при закрытии вкладки.
  Есть кнопки «Сохранить сейчас» и «Загрузить из облака».
- **Другое устройство**: вход с тем же ником и PIN подтягивает прогресс. Если на устройстве уже есть свой
  прогресс, игра спросит, какой оставить. При открытии страницы более новая облачная версия подгружается сама.
- **Рейтинг**: топ-50 игроков с аккаунтом. Очки считает сервер:
  500 за сданный B1 + 20 за каждый день рекорда + 100 за уровень лучшей работы
  + 10 за освоенную комбинацию + 2 за правильный ответ. Результат обновляется после каждого игрового дня.

Защита такая же, как в finance please: PIN хранится как bcrypt-хеш, таблица сохранений закрыта для anon key,
в рейтинге публично видны только ник и очки, писать в рейтинг можно только через `ltv_lb_submit` с токеном
своего аккаунта. В Supabase хранятся 20 последних версий сохранения каждого игрока (`ltv_cloud_saves_history`),
команда для отката есть в конце SQL-файла.
